# План работы и развитие

## Пять часов после получения данных

| Время | Работа | Результат |
|---|---|---|
| 0:00–0:30 | Схема, установка, сверка файлов, первый запуск | Нет ошибок типов и агрегатов |
| 0:30–1:30 | Разбор метрик, ролей и ограничений | Три обязательных CSV и проверенные объяснения |
| 1:30–2:30 | Проверка поиска/графа, разбор нескольких gid | Рабочий основной сценарий аналитика |
| 2:30–3:30 | Пороговая чувствительность и benchmark | Измеренные результаты без ложной accuracy |
| 3:30–4:15 | Чистый запуск, README, обязательные артефакты | Воспроизводимая сдача |
| 4:15–5:00 | Схема решения и репетиция разбора gid | Пятиминутная предметная защита |

Для 3–4 человек: один отвечает за данные/метрики, второй за интерфейс, третий за проверки/документацию, четвёртый за эксперимент и предметный разбор. Если есть ошибки обязательного контура, дополнительные идеи откладываются.

## Миллион узлов

- Читать Parquet колонками и пакетами; агрегировать без загрузки всех отдельных транзакций в Python-объекты.
- Хранить граф в компактных массивах/CSR и выполнять обходы в компилируемой библиотеке.
- Считать временные признаки по отсортированным группам клиентов; использовать очереди с ограниченным окном вместо вложенных переборов.
- Сохранять кластеризацию по компонентам, использовать многоуровневый алгоритм и проверять чувствительность resolution.
- Ограничивать число источников центральности, сообщать приближение и проверять стабильность верхних кандидатов.
- Не встраивать миллион узлов в HTML: сервер выдаёт агрегированный обзор и выбранное окружение.
- Добавить управление версиями данных, доступом, аудит действий и инкрементальное обновление затронутых выводов.

Нынешний файл-ориентированный MVP не заявляет готовую производительность на миллионе узлов. Оценку выполняют на отдельном нагрузочном наборе.

## После хакатона

Пилот измеряет время подготовки принятого аналитического заключения, полноту ссылок на факты и число возвратов на доработку. Автоматическое обновление досье по новой выгрузке и интеграции с банком добавляются после этого. Экономию, продажи и эффект обнаружения нельзя считать доказанными текущим демо.
